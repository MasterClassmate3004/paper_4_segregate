WHAT A CORRECT SPLIT LOOKS LIKE (the house rules)
  - One crop per LEAF = deepest labelled part: Q3, Q3.a, Q3.b.ii, Q2.a.i.1 (numbered tasks only if each has its own [mark]).
  - Shared context goes in a separate STEM crop: Q3.stem (text before part (a)), Q3.b.stem (text before (b)(i)), Q3.c.stem
    (context printed between parts, before part (c) when (c) has no children). Context printed between romans (ii)->(iii)
    goes at the top of the (iii) crop.
  - A figure/table belongs to the FIRST leaf that refers to it ("Fig. 2.1", "Table 3.1", "the data on page 12").
  - Keep: prompt text, figures, tables, boxes the candidate draws in, labelled answer lines ("pH = ........ [2]",
    "type of reaction ........"), and the part's [mark]. Drop: plain dotted answer lines ("..........", "1. .......")
    and blank working space -- do this by splitting the crop into several segments that skip them.
  - Never include: the bare question number (the renderer hides it), "© UCLES", paper codes, "[Turn over", page numbers,
    "BLANK PAGE", "DO NOT WRITE IN THIS MARGIN", "[Total: n]", Section/Option headings and instructions, the
    "For Examiner's Use" column, copyright text, data pages (Periodic Table, "Important values, constants and standards").
  - Nothing cut: every segment edge on a blank row between lines (check with the gate's sliced_boundaries and by eye).
  - Every printed word of question content in exactly one crop (the coverage gate checks this).

KNOWN LAYOUT CASES (learned from earlier batches)
  - A [mark] fused onto the end of a dotted leader ("..........[2]"): keep the row, mask the dots only (a masks rect ending
    just left of the "["), and record the row in accept_plain. Never lose a mark.
  - "State two ... (i) ........ (ii) ........ [2]": bare (i)/(ii) followed only by dots are ANSWER SLOTS, not parts. The leaf
    checker does not expect them. Make ONE crop for the parent (prompt + mark), drop the slot rows. No label-only crops.

  - Lowercase / roman marking-box letters in the "For Examiner's Use" column (x>528) are furniture: leave them out; do not
    widen crops to reach them.
  - A data table printed under the last question ("Important values, constants and standards") and "Qualitative
    Analysis Notes" pages are reference: no crop.
  - Text between the [mark] of one part and the next part's label is that next part's context -- never the end of the
    previous crop: Qn.x.stem for a lettered part (with or without children); for a roman, the top of its own crop.
